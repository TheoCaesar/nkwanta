--------------------------------------------------------------------------------
A NOTE ON ROLES
--------------------------------------------------------------------------------

The system has four roles, and the differences are worth seeing:

  commuter  Reports incidents, follows routes, receives warnings.
            This is what a member of the public gets.

  warden    Field traffic warden. Receives assignments, confirms resolution.

  officer   Control room (MTTD). Sees the dispatch queue, verifies incidents,
            assigns wardens. THIS IS THE PRIMARY ACTOR — the system exists to
            do this person's job.

  admin     Creates privileged accounts, moderates, tunes thresholds.

Self-registration always produces a commuter. There is no request that can
create a privileged account: the registration schema has no role field at all.
Warden, officer and admin accounts come only from the seed script or from an
admin calling POST /auth/users.

--------------------------------------------------------------------------------
SUGGESTED FIVE-MINUTE WALKTHROUGH
--------------------------------------------------------------------------------

1. Open https://nkwanta.onrender.com/
   The map shows current incidents, coloured by confidence. Allow up to 60
   seconds on the first load if the instance has been idle.

2. Open https://nkwanta.onrender.com/docs
   Log in as commuter@nkwanta.demo via POST /auth/login. Copy the
   access_token from the response, click "Authorize" at the top right, and
   paste it in.

3. POST /reports with latitude 5.6037 and longitude -0.1870 (Kwame Nkrumah
   Circle) and incident_type "accident". Watch it appear on the map.

4. Try the same report with the coordinates swapped — latitude -0.1870 and
   longitude 5.6037. It is rejected with a message naming the likely cause.
   PostGIS orders points as (longitude, latitude), the reverse of how people
   speak, and a swap silently moves Accra 600 km out into the Gulf of Guinea
   without raising anything. See docs/explainers/02.

5. Log in as officer@nkwanta.demo to see the dispatch queue: incidents ranked
   by confidence, with the contributing reports and the weight each one
   carried, so the score can be explained rather than merely displayed.
